패스 혜택 · 최종 재검증

2026-09-15 기준 · 일정의 실제 32개 장소 전수 확인

브이패스 = 제주올패스 자유이용권 제주투어패스 = 투어패스몰 자유이용권 * 세부상품·지점·최신 바코드 조건 확인 필요
이번 최종본의 판정 원칙

브이패스 사이트에서 단품 할인 티켓을 판매하는 것과 제주올패스로 무료·추가금 이용 가능한 것을 분리했습니다. 따라서 산방산 탄산온천·도치돌알파카목장처럼 브이패스 단품 특가가 있어도 제주올패스 포함 근거가 확인되지 않으면 빨간 배지를 붙이지 않았습니다.

브이패스 · 제주올패스 확인 4곳 + 재확인 1곳

확인: 스카이워터쇼 · 다이나믹메이즈 · 더마파크 · 글로시말차
최신 바코드 재확인: 뷰 제주하늘

제주투어패스 확인 5곳

확인: 뷰 제주하늘 · 더마파크 · 시소 카이막 애월점 · 상가리야자숲 · 석예원 본초족욕 성산

브이패스 · 공개자료로 금액 산정 가능한 최소 혜택 인당 약 21,000 ~ 21,500원 + α

현재 스케줄 기준: 스카이워터쇼 약 15,000원 + 글로시말차 6,000~6,500원 = 인당 약 21,000~21,500원. 다이나믹메이즈·뷰 제주하늘·더마파크는 제주올패스 정확 적용가가 공개되지 않아 +α로 두었습니다.

현재 제주올패스 판매가 11,900원 기준으로 위 두 곳만 써도 패스값을 넘기는 구조지만, 실제 추가금은 여행 직전 바코드가 최종 기준입니다.
제주투어패스 · 현재 동선의 보수적 확인 혜택 인당 최소 18,500원 + α

현재 스케줄 기준: 뷰 제주하늘 약 9,000원 + 시소 카이막우유 4,000원 + 상가리야자숲 약 5,500원 = 인당 최소 18,500원 + α. 석예원 성산점 본초족욕을 실제 이용하면 +9,000원으로 인당 최소 27,500원 + α입니다. 더마파크는 정확 할인액이 공개되지 않아 α로 남겼습니다.

본초족욕을 석예원 성산으로 실제 방문하면 온라인 대체구매가 약 9,000원 상당이 추가되어 인당 최소 27,500원 + α로 볼 수 있습니다.
